# TIL — Today I Learned

Short, portfolio-ready notes capturing one non-obvious insight from each
phase. Each TIL is a skeleton: hook → insight → example → takeaway. The
author writes the final text in their own voice.

## Why TILs?

The article publishes once. The TILs publish continuously — one per phase
on LinkedIn, the personal blog, or Medium. They keep the work visible
while the article matures.

## Format

Each file:

* Title that states the insight, not the topic
* 100–300 words
* One concrete example (numbers or a formula)
* One-line takeaway
* Tags: phase, math topic, applied domain
